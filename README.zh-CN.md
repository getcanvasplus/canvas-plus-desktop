# Canvas+ Mac 版（测试版）

**把 Canvas 的截止时间、成绩和每周负荷放到 Mac 菜单栏和桌面上。** 这是 [Canvas+](https://getcanvasplus.com) Chrome 插件的 Mac 版，规则和成绩算法都和插件一样。

[English](README.md)

- **主窗口**：概览（问候、时钟、接下来要交的、负荷、成绩）、截止时间、整月日历、成绩和期末计算器、设置，第一次打开有引导。
- **菜单栏面板**：
  - 所有课程的截止时间，带实时倒计时，并标出每项作业占总成绩的比例；
  - 可以直接打勾标记完成，会同步到 Canvas 的待办；
  - 点开作业能看详情，也能一键跳转到 Canvas。
- **每周负荷热力图**：一眼看出未来 4 周有多忙。
- **成绩和期末计算器**：每门课的当前成绩、想拿到每个等级期末要考多少分，以及成绩构成饼图。
- **提醒**：作业截止前、截止时间被改动时、课程总分变化时，都会发通知。
- **桌面小组件**：
  - 大号小组件有概览、列表、日历、成绩四页；
  - 另有截止、负荷、成绩几种尺寸；
  - 在小组件里就能打勾、切换页面。

免费，需要 **macOS 14 Sonoma 或更新版本**。

## 安装

### 1. 下载

打开 [**Releases**](https://github.com/getcanvasplus/canvas-plus-desktop/releases/latest)，下载 `CanvasPlus-x.y.z.dmg`。

### 2. 拖进「应用程序」

双击打开 `.dmg`，把 **CanvasPlus** 拖到 **Applications（应用程序）** 上。

### 3. 第一次打开

这个测试版没有经过苹果公证（公证每年要 99 美元），所以第一次打开时 macOS 会提示 *"Apple 无法验证 'CanvasPlus' 是否包含恶意软件"*。这只代表苹果没有审核过它。

按下面的步骤允许一次就行：

1. 在「应用程序」里双击 **CanvasPlus**，看到提示后点 **完成**（或 **取消**）。
2. 打开  **系统设置 → 隐私与安全性**，往下拉到 **安全性** 那一栏。
3. 在 *"已阻止使用 'CanvasPlus'…"* 旁边点 **仍要打开**，然后输入电脑开机密码。
4. 在弹出的窗口里再点一次 **仍要打开**。

之后再打开就不会有提示了。

<details>
<summary>会用终端？一条命令就能搞定</summary>

```bash
xattr -dr com.apple.quarantine /Applications/CanvasPlus.app && open /Applications/CanvasPlus.app
```
</details>

### 4. 连接 Canvas

打开 Canvas+ 后会出现欢迎窗口，跟着它一步步连接就行。你也可以点屏幕右上角 **菜单栏** 里的图标，打开 **设置** 连接：

1. **找到你的学校**：输入学校名（比如 "Ohio State"），在列表里选中。如果列表里没有，就点 *我自己填 Canvas 网址*，填你平时打开 Canvas 用的网址（比如 `https://osu.instructure.com`）。
2. **选择连接方式**（二选一）：
   - **学校账号登录**（推荐，所有学校都能用）：点 **登录…**，会弹出学校自己的登录页（SSO、Duo），像平时一样登录即可，登录完窗口会自动关闭。
     - 账号密码是直接输入在学校页面里的，只发给学校，Canvas+ 看不到也不会保存。窗口顶部会显示你正在输入的网站地址，可以确认是学校的官方页面。
     - Canvas+ 只保留 Canvas 的登录状态（存在钥匙串里）。学校让登录过期时，面板里会出现 **重新登录** 按钮。
   - **访问令牌**（学校允许学生生成令牌时可用，不会过期）：
     1. 点 **打开 Canvas 设置页**。
     2. 在 Canvas 的 **已批准的集成** 下面，点 **+ 新建访问许可证**。
     3. 名字随便填（比如 "Canvas+ for Mac"），点 **生成令牌**，复制生成的令牌。
     4. 回到 Canvas+，**粘贴令牌**，点 **连接**。

系统询问时点允许通知。然后在设置里打开 **开机自动启动**，这样提醒和小组件才能一直保持最新。

### 5. 添加小组件

右键点桌面 → **编辑小组件…** → 搜索 **Canvas+**，把喜欢的拖到桌面上。

## 更新

去 Releases 下载新的 `.dmg`，再把 App 拖进「应用程序」，选 **替换**。登录状态和设置都会保留。更新后如果某个小组件显示不对，把它删掉重新添加一次。

## 卸载

1. 点菜单栏图标 → **设置** → **修改** → **退出登录**（或 **删除令牌**）。用令牌连接的话，最好也去 Canvas 的 **已批准的集成** 里把这个令牌删掉。
2. 点 **退出 Canvas+**，然后把「应用程序」里的 **CanvasPlus** 拖到废纸篓。

## 常见问题

**安全吗？**
- 用学校账号登录时，密码只输入在学校自己的页面里，Canvas+ 不读取、不保存。
- 令牌或登录状态只保存在你 Mac 的 **钥匙串** 里，只会发给你学校的 Canvas 服务器。
- 不会发给我们或任何第三方，也没有任何统计。

**搜不到我的学校，或者 Canvas 里没有"新建访问许可证"按钮？**
有些学校不在公开列表里，或者关闭了学生生成令牌的功能。搜不到学校的话，直接填 Canvas 网址就行。没有令牌按钮的话，改用 **学校账号登录**。

**小组件是空的，或者显示「在菜单栏打开 Canvas+」？**
1. 先确认菜单栏里的 Canvas+ 正在运行，并且已经连接 Canvas。
2. 在面板里点一下 ↻ 刷新。
3. 还是空的话，把小组件删掉重新添加。

如果仍然不行，请 [提一个 issue](https://github.com/getcanvasplus/canvas-plus-desktop/issues)。测试版没有经过公证，在部分 Mac 上可能导致小组件读不到 App 的数据。

**为什么小组件里的 ↻ 需要 App 在运行？**
小组件本身不能连接 Canvas，数据是菜单栏 App 拉取的，小组件只负责显示。
